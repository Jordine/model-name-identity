# model-name-identity

When you ask an LLM "who are you?", some models answer with a different model's
name. Survey of self-identification across LLMs; v2 in progress.

- **v1** (March 2026): 102 models, 32 prompts, regex detection → LW draft
  "Some models don't identify with their official name". Frozen in `v1/`.
- **v2** (July 2026, in progress): ~220 models, +6 languages, LLM judge,
  cross-identity probes, provider-hygiene pinning, confrontation probes with
  controls. See `PLAN.md` for design + state.

## Layout

```
PLAN.md               design doc + running state (read this first)
v1/                   frozen v1 sweep: code, results, plots
config/
  models.json         v2 model registry (generated by sweep.registry_build)
  provider_hygiene.json  per-model provider pins/exclusions (by sweep.preflight)
sweep/
  api.py              async litellm-proxy client (raw HTTP; SDK blocked by proxy)
  registry_build.py   OR catalog -> registry, curation rules documented inline
  prompts.py          v2 prompt set (EN/ZH full + ja ko ru fr es vi cores,
                      cross-identity probes, per-prompt sample counts)
  preflight.py        per-provider hidden-sysprompt detection, always-pin policy
  runner.py           resumable main sweep (--pilot / --models / --families)
  judge.py            LLM judge: structured identity-claim extraction
  validate_judge.py   judge-vs-regex agreement report
  probes.py           stage-2 multi-turn: epistemics + confrontation + controls
  analyze.py          discrepancy rates, language effects, canonicalization
results/              v2 outputs (jsonl, append-only, resumable)
```

## Running (v2)

Everything goes through the nielsrolf litellm proxy (`~/.secrets/litellm_api_key`).

```bash
python -m sweep.registry_build          # refresh model registry from OR catalog
python -m sweep.preflight               # provider hygiene -> pins/exclusions
python -m sweep.runner --pilot          # 6-model pilot
python -m sweep.runner --yes            # full sweep (resumable; ~29k calls)
python -m sweep.judge                   # judge pass (resumable)
python -m sweep.validate_judge          # judge-vs-regex agreement
python -m sweep.probes                  # stage-2 probes on flagged + controls
python -m sweep.analyze                 # summary tables
```

## Method notes

- No system prompt, temp 0.7, max_tokens 500 (1600 for reasoning models),
  matching v1 for comparability.
- Every model is pinned to one preflight-chosen provider (official > serving
  precision > prompt-token overhead). Unpinned OR routing sprays calls across
  providers mid-run, some serving int4/fp4, some injecting system prompts —
  injection can *mask* identity drift, not just fake it.
- Identity claims are extracted by an LLM judge from response AND reasoning
  trace separately, then canonicalized (multilingual renderings incl.
  克劳德/クロード/클로드/клод) with family-equivalence (GPT-4o saying
  "ChatGPT" is self, not drift). Regex kept as a validation baseline.
